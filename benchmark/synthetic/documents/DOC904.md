# DOC904 - Security Incident Response Policy

Version: 1.0
Effective date: 2026-02-15
Status: Synthetic engineering document

## Initial notification

A suspected security incident must be reported to the security team within one
hour of discovery.

## Project notification

If the incident affects a project system or project data, the project manager
must be informed within four hours of discovery.

## Documentation

The incident record must include the discovery time, affected system, initial
assessment, and actions taken.
