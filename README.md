# Responsible Agentic Workflows

Research prototype for an ongoing master's thesis in digitalization and management at the University of South-Eastern Norway (USN).

The project studies how explicit guardrails affect the task quality, reliability, latency, and resource use of LLM-based workflows. The evaluation design compares a retrieval baseline, a matched agentic workflow, and a guardrailed agentic workflow under comparable conditions.
