# UC1 - OptFor-EU Forest Policy

## Current status

The final benchmark uses a frozen UC1 retrieval scope of 30 active documents
and primary tasks T001–T010. This README was originally written during corpus
selection; [the frozen scope](benchmark_scope.json) and the
[primary benchmark tasks](../../../benchmark/tasks/UC1/) describe the later
completed research state.

## Purpose

UC1 is the first real document-based knowledge-work use case in the thesis.

Its source context is the OptFor-EU forest policy environment. The use case may
contain multiple policy, strategy, regulation, report, or related documents
identified through the OptFor-EU policy resources.

Each original document is treated as a separate corpus document with its own
provenance record.

Multiple source documents inside UC1 do not create additional use cases.

UC2 and UC3 were subsequently defined and included in the completed primary
benchmark; see the [three-use-case overview](../../README.md).

## Local storage

Original source files:

`corpus/use_cases/UC1/raw/`

Processed representations:

`corpus/use_cases/UC1/processed/`

Working originals are excluded from this corpus directory by default. A
[rights-reviewed public source subset](../../../research-artifacts/study-a/source-documents/README.md)
is released separately with source attribution and recorded identities.
