# UC1 Benchmark Task Human Review

Date: 2026-09-12

## Scope

The UC1 benchmark task set contains ten tasks:

- 3 direct-retrieval tasks;
- 3 within-document reasoning tasks;
- 2 cross-document reasoning tasks;
- 2 insufficient-evidence tasks.

The task questions, task types, reference answers, and source-evidence
relationships were reviewed before human verification.

## Review outcome

The researcher approved the UC1 task set after review on 2026-09-12, subject
to four minor wording revisions identified before verification.

The approved revisions were:

1. T007 was changed from a question that presupposed increased ambition to a
   neutral question asking how the 2023 amendment changed the LULUCF framework.
2. T008 changed "requiring strict protection" to "calling for strict
   protection" in the reference answer to avoid overstating the legal force of
   the Forest Strategy.
3. T009 was rewritten for grammatical clarity without changing the information
   need.
4. T010 now uses the corpus terminology "strict protection" rather than
   "strict legal protection".

No task type, required document, reference-evidence location, or benchmark
allocation was changed by these revisions.

## Insufficient-evidence tasks

T009 and T010 remain insufficient-evidence tasks.

Their expected behavior is abstention from a substantive numerical answer
because the frozen UC1 corpus does not provide sufficient evidence for the
requested observed 2025 outcomes.

The separate corpus-wide authoring audit remains the supporting record for
those decisions.

## Methodological boundary

Human verification does not freeze the task set.

No B0, B1, or G1 benchmark run was used to create, select, revise, or verify
the tasks.

A separate final validation step is required before the UC1 task set can be
marked frozen.
